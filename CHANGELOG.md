# Nexo 0.0.3 Alpha

## Интерфейс
- Единая навигация: Обзор, Диалоги, Люди и Сообщества.
- Убраны вложенные вкладки и повторяющиеся панели.
- Обновлены карточки, состояния наведения, аватары и группировка сообщений.
- Сохранены терракотовый акцент, типографика и короткие анимации переходов.
- Обновлён экран приветствия и добавлен двухэтапный экран запуска с 30 оригинальными фразами.

## Аккаунты
- Подтверждение пароля при регистрации.
- Проверка доступности ника до сохранения профиля.
- Цвет аватара и короткое описание профиля.
- Сессии настольного приложения хранятся в SQLite, а не в памяти процесса.
- Настройка «Запомнить устройство» задаёт постоянную 30-дневную сессию.

## Desktop
- Нативная Windows title bar overlay с системными кнопками окна и поддержкой Snap Layouts.
- Цвет системной полосы заголовка синхронизируется с темой приложения.
- Проверка обновлений при запуске и вручную из настроек.
- Установщик нового Alpha-релиза загружается автоматически; перед установкой Nexo просит подтвердить перезапуск.

## Честные ограничения
- Восстановление пароля не показывается как действующая функция: для отправки ссылок сброса нужен подключённый почтовый сервис.
- Голосовые каналы сообществ пока не поддерживают полноценную передачу аудио; нерабочие кнопки управления убраны.
