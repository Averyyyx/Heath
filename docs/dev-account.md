# Тестовый аккаунт разработчика

Обычный пользователь с бессрочной премиум-подпиской и значками `dev` и `premium`.
Нужен, чтобы заходить в приложение и проверять премиум-интерфейс без оплаты.
Админских прав (баны, модерация, доступ к чужим данным) у него **нет**.

- Логин по умолчанию: `dev@hearth.local` (меняется переменной `HEARTH_DEV_EMAIL`)
- Пароль: случайный, создаётся при первом запуске и сохраняется в файл `dev-account.txt`
  в папке данных (в лог он не попадает). Свой пароль можно задать переменной `HEARTH_DEV_PASSWORD`.

## Как включить

| Как запускаете | Что делать |
| --- | --- |
| `npm start` / `npm run electron:dev` (из исходников) | Ничего: аккаунт создаётся сам. Файл с паролем: `%APPDATA%\Nexo\data\dev-account.txt` |
| Установленное приложение (.exe) | Создайте пустой файл `%APPDATA%\Nexo\dev-account.enabled` и перезапустите приложение |
| Только сервер (`npm run dev`) | Задайте `HEARTH_DEV_ACCOUNT=true` (PowerShell: `$env:HEARTH_DEV_ACCOUNT="true"; npm run dev`). Файл с паролем: `data/dev-account.txt` в папке проекта |

Выключить: переменная `HEARTH_DEV_ACCOUNT=0` (или удалить файл `dev-account.enabled`).
Уже созданный аккаунт при этом остаётся в базе — чтобы убрать его совсем, удалите базу
(`app.db` в папке данных) или саму строку пользователя.

## Безопасность

- Аккаунт не создаётся на боевом веб-деплое (когда `CLIENT_ORIGIN` начинается с `https://`
  или включён `REQUIRE_HTTPS`), даже если флаг случайно оставлен.
- Подписка создаётся напрямую в базе, без записей в `premium_transactions`, поэтому баланс
  и отчётность не искажаются.
- Не публикуйте `dev-account.txt` и не коммитьте его в репозиторий (папка `data/` уже в `.gitignore`).
